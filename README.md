# 🌤️ Simple Dastyar — Chrome New Tab Dashboard

A clean, minimal **Chrome new tab extension** that turns every new tab into your personal productivity space — complete with a **calendar**, **notes**, **quick access links**, and a **Google search bar**.  
Built entirely with **HTML + CSS + JavaScript**.

---

## ✨ Features

- 🗓️ **Calendar:** Interactive Gregorian calendar with today highlight and note indicators.  
- 📝 **Notes:** Create, edit, delete, and link notes to specific calendar dates.  
- ⚡ **Quick Access:** Add your favorite websites as shortcuts with automatic favicons.  
- 🔍 **Search Bar:** Instantly search Google from your new tab.  
- 💾 **Offline Storage:** All data saved locally using `localStorage`.  
- 🎨 **Smooth Animations:** Subtle fade-in effects for a polished feel.  

> 🛠️ *Upcoming:* Persian (Jalali) calendar mode and dark theme support.

## 🚀 Installation

1. Clone or download this repository:
   ```bash
   git clone https://github.com/<your-username>/simple-dastyar.git
2.Open Google Chrome and go to:

```
chrome://extensions/
```
3.Turn on Developer Mode (toggle in the top-right corner).

4.Click Load unpacked and select this project folder.

5.Open a new tab — enjoy your Simple Dastyar dashboard 🎉
